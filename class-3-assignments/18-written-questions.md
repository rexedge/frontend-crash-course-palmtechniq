# Assignment 18 — Written Questions

**Type:** Review · **Difficulty:** ⭐ · **Time:** ~20 min
**Prereqs:** all of Class 3
**Answer in:** `work/18-written-questions/answers.md` (or any text file)

---

## Goal

Answer from memory, in your own words, **without scrolling back through the lesson**. If you can't answer one, that's the section to re-read.

---

1. Why is external CSS taught as the default instead of inline `style=""` or a `<style>` block? Give two reasons.

2. In your own words: what are the four parts of the box model, from the inside out?

3. What is the practical difference between `margin` and `padding`? Give one case where only `padding` is correct, and one where only `margin` is correct.

4. What exactly does `box-sizing: border-box` change, and why do many stylesheets set it on every element?

5. Put these selectors in order of **specificity**, lowest to highest: `.menu li a`, `a`, `#logo`, `nav a`.

6. When would you reach for `rem` vs `px` vs `%`?

7. What's the difference between `display: none` and just giving an element the same colour as its background?

8. `color` vs `background-color` — which is the text and which is behind it?

9. Two rules set `color` on the same element with **equal** specificity. Which one wins?

10. An element has `width: 250px; padding: 20px; border: 5px solid`, default `box-sizing`. What is its rendered width on screen? What would it be with `border-box`?
