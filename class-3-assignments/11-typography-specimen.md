# Assignment 11 — Typography Specimen

**Type:** Core · **Difficulty:** ⭐⭐ · **Time:** ~35 min
**Prereqs:** Class 3 §8 (typography)
**Build in:** `work/11-typography-specimen/index.html` + `style.css`

---

## Goal

Build a one-page "type specimen" that demonstrates every typography property from the lesson, each clearly labelled.

## What you'll practice

- `font-size` across a wide range, `font-weight`, `line-height`, `letter-spacing`, `text-align`
- Seeing what each property actually does to real text

## Instructions

Build `index.html` + `style.css` demonstrating, each as its own labelled block:

1. **Size range** — the same short phrase at ~6 sizes from `0.75rem` to `4rem`.
2. **Weight** — the same sentence at `font-weight` 300, 400, and 700 (use a class each).
3. **Line height** — one real paragraph (3–4 sentences) shown twice: once `line-height: 1.2`, once `line-height: 1.8`. Side note on which is easier to read and why.
4. **Letter spacing** — an ALL-CAPS heading shown at `letter-spacing: 0` and `letter-spacing: 0.1em`.
5. **Alignment** — the same paragraph three times: `text-align: left`, `center`, `justify`.

Label every demo with a small heading or a `.label` line saying what it shows.

## Requirements

- [ ] All five demos present and labelled
- [ ] The size range spans at least `0.75rem` to `4rem`
- [ ] Weight demo uses 300 / 400 / 700
- [ ] Line-height demo uses the **same** paragraph text for both versions
- [ ] Alignment demo uses the **same** paragraph text for all three

## Acceptance criteria

- Each property's effect is obvious because only that property changes between the paired/tripled samples.
- Your line-height note correctly prefers the looser one for body reading.

## Hints

<details><summary>Show hint</summary>

Keep the font family the same throughout — this is a *specimen* of one typeface behaving under different settings, not a font comparison. Changing two things at once hides which one caused the effect.
</details>
