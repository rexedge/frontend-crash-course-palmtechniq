# Assignment 19 — Course Homework: Five Logic Functions

**Type:** Core · **Difficulty:** ⭐⭐ · **Time:** ~45 min · 🧵 keep this file
**Prereqs:** [Assignment 11](11-the-classic-ten.md) and [Assignment 15](15-loop-toolkit.md)
**Build in:** `work/19-five-logic-functions/index.html` + `app.js`

---

## Goal

Rewrite five functions **from scratch**, in a fresh file, without looking at your earlier work. This is the Class 6 homework — the one that gets checked.

## What you'll practice

- Recalling the patterns instead of copying them
- Starting from an empty file: the `<script>` tag, the function, the tests
- Finding your own bugs with the Console

## Instructions

1. Look back over [Assignment 11](11-the-classic-ten.md) and [Assignment 15](15-loop-toolkit.md). Pick the **five** functions you found hardest, or never quite finished. Then close those files.
2. Make a new, empty folder. Type the `index.html` starter page and an empty `app.js`.
3. Write your five functions. Your choice must include:
   - at least one that makes a decision with `if`
   - at least one that uses a loop
   - at least one that works on an array or a string
4. Above each function, write a one-line comment saying in plain words what it does.
5. Under each function, log three test calls with the expected answer in a comment. One of the three should be an awkward value: zero, a negative number, an empty string, or an empty array.
6. If you get stuck for more than 10 minutes, re-read the matching section of the lesson — not your old code.

## Requirements

- [ ] Five functions, in a new file, typed from scratch
- [ ] Every one **returns** its answer; none has a `console.log` inside
- [ ] At least one `if`, at least one loop, and at least one function that takes an array or a string
- [ ] A plain-words comment above each function
- [ ] Three logged test calls for each, including one awkward value
- [ ] No red in the Console

## Acceptance criteria

- All fifteen test calls print the answer written in their comment.
- Nothing in the file uses anything from the "not yet" list in the [README](README.md).
- You could explain any line of the file to someone else, out loud.

Invent a sixth function of your own that solves a small problem from your own life — splitting rent, converting a currency, counting the days until something. Give it a clear name and three tests.
