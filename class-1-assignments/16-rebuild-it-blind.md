# Assignment 16 — Rebuild It Blind

**Type:** Challenge · **Difficulty:** ⭐⭐⭐ · **Time:** ~30 min
**Prereqs:** Assignment 08 (About Me) finished
**Build in:** `work/16-rebuild-it-blind/index.html`

---

## Goal

Rebuild your About Me page from memory, then compare it against the original to find exactly which tags and rules you haven't internalised yet.

## What you'll practice

- Recalling the full skeleton and tag set with no reference
- Honest self-assessment of what you actually know vs what you can only copy

## Instructions

1. Open your finished `work/08-about-me-page/index.html` and **look at it in the browser for 60 seconds**. Don't read the code — just the rendered page.
2. Close that file and the lesson. Open a **blank** `work/16-rebuild-it-blind/index.html`.
3. Rebuild the page from memory: same sections, same kinds of content. Don't stress about matching the exact words — match the **structure** (heading, intro, likes list, goals list, link, image).
4. Only when you're completely stuck, glance at the original, note what you forgot, then keep going.
5. When done, put the two files side by side and list every difference: missing tags, wrong nesting, forgotten `alt`, skipped closing tags, etc.

## Requirements

- [ ] A from-memory rebuild containing all the Assignment 08 parts (h1, intro p, ul, ol, link, img with alt)
- [ ] Valid skeleton, tags closed in order
- [ ] A written list (in the file as a comment, or a separate `notes.txt`) of every difference you found and what you'd forgotten

## Acceptance criteria

- The rebuild renders as a recognisable About Me page.
- Your differences list is specific ("forgot the `alt` on the image", "closed `</ul>` before the last `</li>`") — not vague ("some stuff was wrong").
