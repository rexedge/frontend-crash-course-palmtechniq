# Your Class 1 work goes here

One folder per assignment, each with its own `index.html`:

```
work/
  01-skeleton-from-memory/index.html
  02-heading-ladder/index.html
  08-about-me-page/index.html
  09-recipe-page/index.html
  15-three-page-mini-site/index.html   (also about.html, hobbies.html, contact.html)
  ...
```

Open any `index.html` with the **Live Server** extension: right-click the file in VS Code → "Open with Live Server". The browser reloads automatically every time you save.

Keep every file even after it's "done":
- **08 (About Me)** and **15 (mini-site)** get rebuilt with semantic tags in Class 2, styled in Class 3, laid out in Classes 4–5, and made interactive in Class 7.
- The spaced-review sets ask you to rebuild these from a blank file later.
