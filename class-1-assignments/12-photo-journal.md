# Assignment 12 — Photo Journal

**Type:** Core · **Difficulty:** ⭐⭐ · **Time:** ~25 min
**Prereqs:** Class 1 §4 (images, headings, paragraphs)
**Build in:** `work/12-photo-journal/index.html`

---

## Goal

Build a "things I saw this week" page: five entries, each a heading, an image, and a caption — in a consistent repeating shape.

## What you'll practice

- Repeating a fixed pattern (`<h2>` → `<img>` → `<p>`) five times, identically
- Writing specific `alt` text for every image
- Keeping structure consistent across entries

## Instructions

Build `index.html`:

- `<h1>` — `Five Things I Saw This Week`
- one intro `<p>`
- **five entries**, each exactly:
  1. an `<h2>` — a short title for the thing
  2. an `<img>` — `src` can be `https://picsum.photos/400/300` or any real image URL
  3. a `<p>` — 1–2 sentences describing what it was and where
- Every `<img>` gets an `alt` that describes the picture.

## Requirements

- [ ] `<h1>` + intro `<p>`
- [ ] Exactly 5 entries, each with the same `<h2>` → `<img>` → `<p>` shape
- [ ] Every image has a written, specific `alt`
- [ ] Entries appear in a consistent order every time
- [ ] Valid skeleton; no CSS or non–Class-1 tags

## Acceptance criteria

- The five entries are visually uniform — same parts, same order.
- Each `alt` describes its image well enough to picture it without seeing it.

## Hints

<details><summary>Show hint</summary>

Build the first entry completely, get it right, then copy its shape for the other four and change only the words and the image. Consistency is the skill being practised here.
</details>
