# Assignment 08 — About Me Page

**Type:** Core · **Difficulty:** ⭐⭐ · **Time:** ~35 min · 🧵 keep this file
**Prereqs:** Class 1 §3–6 (skeleton, core tags, nesting, guided practice)
**Build in:** `work/08-about-me-page/index.html`

---

## Goal

Build a complete page about yourself using **only Class 1 tags**. This is the core deliverable of Class 1. You will rebuild it with semantic tags in Class 2, style it in Class 3, lay it out in Classes 4–5, and make it interactive in Class 7 — so do it properly now.

## What you'll practice

- Combining headings, paragraphs, lists, a link, and an image into one coherent page
- Correct nesting and indentation across a whole document
- Working only within a known toolset

## Instructions

Build `index.html` about yourself. It must contain **all** of the following, in a sensible order:

- a `<title>` (in `<head>`) with your name
- one `<h1>` — your name
- one intro `<p>` — 2–3 sentences about who you are
- one `<h2>` titled `Things I Like`
- one `<ul>` with **at least 3** `<li>` items
- one `<h2>` titled `My Goals`
- one `<ol>` with **at least 3** `<li>` items, in priority order (this is why it's ordered)
- one `<h2>` titled `A Link`
- one `<a>` link to any website you like, with descriptive link text
- one `<img>` with a real `src` and a **written** `alt`

Write your own content — do not copy the example from the lesson.

## Requirements checklist

- [ ] Valid skeleton; `<title>` has your name
- [ ] One `<h1>` (your name)
- [ ] Intro `<p>`, 2–3 sentences
- [ ] `<h2>` "Things I Like" + `<ul>` with 3+ `<li>`
- [ ] `<h2>` "My Goals" + `<ol>` with 3+ `<li>` in priority order
- [ ] `<h2>` "A Link" + one `<a>` with descriptive text and a valid `href`
- [ ] One `<img>` with `src` **and** a specific written `alt`
- [ ] Everything is inside `<body>`; every tag is closed in the right order; nested tags are indented
- [ ] No CSS, no `class`/`id`, no tags outside the Class 1 list

## Acceptance criteria

- Open with Live Server: the page reads top-to-bottom as a short profile of you.
- The browser tab shows your name.
- The image loads and has meaningful `alt` (test it by temporarily breaking the `src`).
- Run through the [Troubleshooting table in the lesson](../class-1-welcome-to-the-web-html-basics.md) — none of those problems are present.
