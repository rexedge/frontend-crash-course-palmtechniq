# Assignment 17 — Reference Sheet

**Type:** Challenge · **Difficulty:** ⭐⭐ · **Time:** ~25 min
**Prereqs:** Class 1 (all of it)
**Build in:** `work/17-reference-sheet/index.html`

---

## Goal

Build your own single-page HTML reference covering every tag from Class 1. You'll extend this same page after every future class.

## What you'll practice

- Explaining each tag in your own words
- Organising reference material with headings and lists
- Building something you'll actually reuse

## Instructions

Build `index.html`:

- `<h1>` — `My HTML Reference`
- one `<p>` — "Started in Class 1. I add to this every class."
- one `<h2>` per tag you learned this class: `<html>`, `<head>`, `<title>`, `<body>`, `<h1>`–`<h6>`, `<p>`, `<a>`, `<img>`, `<ul>`, `<ol>`, `<li>`
- under each `<h2>`:
  - a `<p>` — what the tag is for, in your own words
  - a `<p>` — an example **described in words** (you can't show raw tags without more HTML, so write: "opening angle bracket, the letter p, closing angle bracket, your text, then `</p>`")
  - a `<p>` — one gotcha or rule (e.g. for `<img>`: "self-closing, always needs `alt`")

## Requirements

- [ ] `<h1>` + intro `<p>`
- [ ] An `<h2>` section for every Class 1 tag
- [ ] Each section has: purpose `<p>`, example-in-words `<p>`, gotcha `<p>`
- [ ] Descriptions are yours, not copied from the lesson
- [ ] Valid skeleton; no CSS or non–Class-1 tags

## Acceptance criteria

- Every Class 1 tag is covered.
- You could use this page to jog your memory without opening the lesson.
- The gotcha lines capture the mistakes *you* actually made this week.
