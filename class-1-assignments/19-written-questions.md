# Assignment 19 — Written Questions

**Type:** Review · **Difficulty:** ⭐ · **Time:** ~15 min
**Prereqs:** all of Class 1
**Answer in:** `work/19-written-questions/answers.md` (or any text file)

---

## Goal

Answer these from memory, in your own words, **without scrolling back through the lesson**. If you can't answer one, that's the section to re-read.

---

1. What are the three main languages of the web, and what is each one responsible for?

2. What is the difference between what goes inside `<head>` and what goes inside `<body>`?

3. When should you use `<ol>` instead of `<ul>`? Give one real example of each.

4. What is an **attribute**? Name two attributes and the tag each one belongs to.

5. Why must every `<img>` have an `alt`? Name two different situations where the `alt` text actually matters.

6. What does "nesting" mean? What is the rule about the **order** you close nested tags?

7. Why is `index.html` a special file name?

8. Indentation does not change how the browser renders the page. So why bother doing it?

9. Name three tags that are **self-closing** (no separate closing tag). *(Hint: from Class 1 you've met `<img>`; from the skeleton, `<meta>`; and `<link>` if you did the stretch.)*

10. What's the difference between a **tag** and an **element**?
