## How to use this folder

- Do **all warm-ups (01–07)** in order — each is short, they build the muscle memory for typing HTML.
- Work through the **core set (08–14)** — these are the real builds. Finish at least **08 (About Me)**; it's the class hands-on and it gets reused in every later class.
- Do **debug (18)** and pick from **challenge (15–17)** as time allows.
- Answer the **written questions (19)** from memory, in a text file.
- Put your code in `work/<assignment-slug>/index.html` (one folder per assignment). See [work/README.md](work/README.md).
- **Type everything by hand — do not copy-paste.** Save often (`Ctrl+S`). Check the browser (Live Server) after every change.
- If something breaks, re-read your code line by line, out loud. ~90% of Class 1 bugs are a missing closing tag or a typo.

## Scope — only what's been taught

Use **only** these tags:

`<!DOCTYPE html>`, `html`, `head`, `title`, `body`, `h1`–`h6`, `p`, `a` (with `href`), `img` (with `src`, `alt`), `ul`, `ol`, `li`

Plus: correct **nesting** and **indentation**.

**Not yet — do not use:**
- CSS of any kind (no `style` attribute, no `<style>`, no `.css` file) — your pages will be plain black text on white, and that is correct
- `class` or `id` attributes
- `div`, `span`, `br`, `strong`, `em`
- semantic tags (`header`, `nav`, `main`, `section`, `article`, `footer`) — that's Class 2
- tables and forms — also Class 2
