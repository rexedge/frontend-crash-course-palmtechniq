# Assignment 10 — Study Notes Page

**Type:** Core · **Difficulty:** ⭐⭐ · **Time:** ~35 min
**Prereqs:** Class 1 (all of it)
**Build in:** `work/10-study-notes-page/index.html`

---

## Goal

Turn the Class 1 lesson itself into your own notes page. This forces you to re-explain every concept in your own words — the best kind of revision.

## What you'll practice

- Structuring a longer document with `<h1>` + several `<h2>` sections
- Summarising into `<ul>` key-point lists
- Writing explanations in `<p>` from memory

## Instructions

Build `index.html`:

- `<h1>` — `HTML Basics — My Notes`
- One `<h2>` section per topic from Class 1:
  - `What HTML Is`
  - `The Document Skeleton`
  - `Headings`
  - `Paragraphs`
  - `Links`
  - `Images`
  - `Lists`
  - `Nesting`
- Under each `<h2>`: one `<p>` explaining the idea **in your own words**, then a `<ul>` of 2–4 key points or gotchas.
- End with an `<h2>` `Questions I Still Have` and a `<ul>` — be honest; these are what to ask about or look up.

## Requirements

- [ ] `<h1>` + 8 topic `<h2>` sections + a final "Questions" `<h2>`
- [ ] Every topic section has both a `<p>` and a `<ul>`
- [ ] Explanations are yours, not copied sentences from the lesson
- [ ] Valid skeleton; tidy indentation; no CSS or non–Class-1 tags

## Acceptance criteria

- You could hand this page to another beginner and they'd learn the basics from it.
- Every section has an explanation *and* a bullet list.
- The "Questions I Still Have" list is not empty (if it is, you skimmed — go deeper).

## Hints

<details><summary>Show hint</summary>

Write each explanation *without looking*, then check it against the lesson and fix anything wrong. The gap between what you wrote and what's correct is exactly what you need to study.
</details>
