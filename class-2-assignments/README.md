## How to use this folder

- Do **all warm-ups (01–06)** in order — each is short, they build the muscle memory.
- Work through the **core set (07–14)** — these are the real builds. Aim to finish at least 07, 08, and 11.
- Do **debug (18)** and pick from **challenge (15–17)** as time allows.
- Answer the **written questions (19)** from memory, in a text file.
- Put your code in `work/<assignment-slug>/index.html` (one folder per assignment). See [work/README.md](work/README.md).
- **Type everything by hand.** Save often. Check the browser after every change.

## Scope — only what's been taught

Use only Class 1 + Class 2 material. **No CSS yet** — your pages will look like a plain vertical stack of text, and that is correct.

Allowed tags:
- Everything from Class 1: `h1`–`h6`, `p`, `a`, `img`, `ul`, `ol`, `li`
- Structure: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `div`, `span`
- Tables: `table`, `caption`, `thead`, `tbody`, `tr`, `th` (with `scope`), `td`
- Forms: `form`, `label` (with `for`), `input`, `textarea`, `select`, `option`, `button`, `fieldset`, `legend`
- Attributes: `id`, `name`, `type`, `for`, `required`, `placeholder`, `minlength`, `maxlength`, `min`, `max`, `pattern`, `value`, `rows`, `disabled`, `selected`, `scope`
