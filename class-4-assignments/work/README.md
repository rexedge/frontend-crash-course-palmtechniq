# Your Class 4 work goes here

One folder per assignment, usually with both `index.html` and `style.css`:

```
work/
  01-turn-it-on/              index.html  style.css
  07-navbar/                  index.html  style.css
  08-three-card-feature-row/  index.html  style.css
  13-contact-form-two-columns/  index.html  style.css
  ...
```

Open `index.html` with the **Live Server** extension. Keep dev tools open — Chrome/Edge draw an
overlay on any element with `display: flex` (look for the small "flex" badge next to it in the
Elements panel); clicking it highlights the main axis and cross axis directly on the page, which
is the fastest way to see what's actually going on.

**Assignment 13** styles the contact form you've been building since Class 2. Copy it in first:
- `class-3-assignments/work/08-style-contact-form/` → `work/13-contact-form-two-columns/`

You're changing the **layout** of the fields, not the form's structure or validation — keep every
`label`, `input`, `required`, etc. exactly as it was.

**Assignment 15** does the same with the Class 3 blog homepage:
- `class-3-assignments/work/15-style-blog-homepage/` → `work/15-blog-homepage-with-flexbox/`
