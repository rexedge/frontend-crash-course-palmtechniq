# Frontend Development Crash Course — PalmTechnIQ

A self-guided, beginner-friendly crash course in **HTML, CSS, and JavaScript fundamentals**.
Eight classes take you from a blank file to a small responsive, interactive personal portfolio
page built from scratch — **no frameworks** — with an emphasis on understanding *why* each piece
works, not just copying it.

**Audience:** complete beginners, no prior coding experience.
**License:** [CC BY 4.0](LICENSE) — reuse and adapt freely with attribution.

## How this repo is organised

| File / folder | What it is |
|---|---|
| [`frontend-crash-course-palmtechniq.md`](frontend-crash-course-palmtechniq.md) | The **syllabus** — what each class covers, its live exercise, and its homework. |
| `class-<n>-<topic>.md` | **Self-guided lesson read-throughs.** Read a section, do the "Practice Now" box, move on. |
| [`assignments.md`](assignments.md) | The full **assignment bank** for all 8 classes in one file (warm-ups, core builds, challenges, debugging drills, written questions). |
| `class-<n>-assignments/` | The same assignments **broken out one-per-file**, with a folder `README.md` index and a `work/` folder for your code. |

Every lesson and assignment set stays inside a strict **scope** — it only uses concepts taught up
to that point. Each one lists its "in scope / not yet" tags and properties explicitly.

## How to use it

1. **Tools:** install [VS Code](https://code.visualstudio.com/) and the **Live Server**
   extension (by Ritwick Dey). That's the whole toolchain — no Node, no build step.
2. **Per class:** read `class-<n>-<topic>.md` top to bottom, doing every "Practice Now" box as
   you reach it.
3. **Then:** open `class-<n>-assignments/README.md` (or the Class `<n>` section of
   `assignments.md`) and work the assignments. Build your code in
   `class-<n>-assignments/work/<assignment-slug>/index.html` and open it with Live Server.
4. **Type everything by hand** — don't paste. Save often, check the browser after every change.
5. Assignments marked 🧵 feed into the Class 8 capstone — keep those files.
