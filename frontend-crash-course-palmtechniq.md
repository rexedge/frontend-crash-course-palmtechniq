# Frontend Development Crash Course — PalmTechnIQ
**Track:** HTML / CSS / JavaScript Fundamentals
**Audience:** Complete beginners (no prior coding experience)
**Format:** 8 classes, 2x/week for 4 weeks, 1 hr 30 min per session

---

## Course Goal
By the end of 8 sessions, students should be able to build a simple, responsive, interactive static web page from scratch — without a framework — and understand *why* each piece works, not just how to copy it.

## Structure per Session (90 min)
- **10 min** — Recap + Q&A on homework
- **25 min** — Concept teaching (live-coded, not slides-only)
- **40 min** — Guided hands-on practice (students code alongside you)
- **15 min** — Independent mini-challenge + homework assignment

---

## Week 1

### Class 1 — Welcome to the Web + HTML Basics
- What happens when you visit a website (browser, HTML/CSS/JS roles, client vs server — high level only)
- Setting up: VS Code, Live Server extension, folder structure
- HTML document skeleton: `<!DOCTYPE>`, `html`, `head`, `body`
- Core tags: headings, paragraphs, links, images, lists
- **Hands-on:** Build a simple "About Me" page
- **Homework:** Add 3 more sections to the About Me page using only what was taught

### Class 2 — HTML Deep Dive: Structure & Forms
- Semantic HTML: `header`, `nav`, `main`, `section`, `article`, `footer` — and why semantics matter (accessibility, SEO)
- Tables (brief — when to use, when not to)
- Forms: `input` types, `label`, `button`, `textarea`, basic validation attributes
- **Hands-on:** Build a semantic-structure contact form page
- **Homework:** Rebuild the About Me page from Class 1 using semantic tags

---

## Week 2

### Class 3 — CSS Basics
- How CSS connects to HTML (inline, internal, external — teach external as best practice)
- Selectors: element, class, id, descendant
- The box model: content, padding, border, margin (this is the single most important concept — spend real time here)
- Colors, typography basics, `background`
- **Hands-on:** Style the About Me page
- **Homework:** Style the contact form page from Class 2

### Class 4 — CSS Layout: Flexbox
- Why layout is hard without Flexbox/Grid (brief history: floats → flexbox)
- `display: flex`, main axis vs cross axis
- `justify-content`, `align-items`, `flex-wrap`, `gap`
- **Hands-on:** Build a navbar and a 3-card layout using Flexbox
- **Homework:** Convert the contact form into a two-column flex layout

---

## Week 3

### Class 5 — CSS Grid + Responsive Design
- `display: grid`, `grid-template-columns/rows`, `gap`
- When to use Grid vs Flexbox (2D vs 1D — keep it simple)
- Media queries and mobile-first thinking
- **Hands-on:** Build a responsive photo gallery (Grid) that reflows on mobile
- **Homework:** Make the About Me + Contact pages responsive

### Class 6 — JavaScript Basics
- What JS actually does on a page (behavior layer)
- Variables (`let`/`const`), data types, operators
- Functions, conditionals, basic loops
- Console.log and the browser dev tools (teach debugging habits early)
- **Hands-on:** Small logic exercises (e.g., simple calculator functions)
- **Homework:** Write 5 small functions solving basic logic problems

---

## Week 4

### Class 7 — JavaScript + the DOM
- What the DOM is, `document.querySelector`/`querySelectorAll`
- Changing content, styles, and classes with JS
- Event listeners: `click`, `input`, `submit`
- **Hands-on:** Make the contact form show a "Thank you" message on submit without reloading; add a light/dark mode toggle button
- **Homework:** Add one new interactive feature to any earlier page

### Class 8 — Capstone Mini-Project + Wrap-Up
- Students combine everything: a small responsive, interactive personal portfolio page (HTML structure + CSS Flexbox/Grid + JS interactivity)
- Peer review / show-and-tell (10 min per student if group is small)
- Recap of the whole course + where this fits into the fuller PalmTechnIQ path (CSS frameworks, JS deeper dive, then frontend frameworks)
- **Deliverable:** A working portfolio page each student can point to as "I built this"

---

## Notes for Facilitation
- Live-code everything — don't just show finished code. Beginners learn from watching mistakes get fixed.
- Keep a shared repo or folder structure per student so progress is visible week to week.
- Consider a simple numeric completion checklist per class (consistent with PalmTechnIQ's scoring system) if you want to track readiness before students move to the next phase.
