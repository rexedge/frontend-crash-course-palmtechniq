# Assignment 25 — Written Questions

**Type:** Review · **Difficulty:** ⭐ · **Time:** ~15 min
**Prereqs:** all of Class 7
**Answer in:** `work/25-written-questions/answers.md` (or any text file)

---

## Goal

Answer from memory, in your own words, **without scrolling back through the lesson**. If you can't answer one, that's the section to re-read.

---

1. What is the DOM? How is it related to the HTML file you wrote — and how is it different?

2. `querySelector` vs `querySelectorAll` — what does each one give back, and how do you use the result?

3. Why does it matter where the `<script>` tag goes? Give two ways to make sure the page has been built before your code runs.

4. `textContent` vs `innerHTML` — when is each one the right choice, and what's the risk with one of them?

5. What does `event.preventDefault()` do? Name two events where you'd want it.

6. What is `event.target`? Why is it useful when one function looks after many elements?

7. Describe three things `classList` lets you do. Why is switching a class usually better than setting `.style` directly?

8. Walk through, in order, everything that happens between "the user clicks a button" and "the text on the page changes".

9. In `button.addEventListener("click", handleClick)`, why are there no brackets after `handleClick`? What happens if you add them?

10. What type is `input.value`, even for `type="number"`? What do you do before using it in a sum — and what's the catch with an empty box?
