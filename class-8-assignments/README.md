## How to use this folder

- This class has **one** required build: **01 (personal portfolio)**. It's the course deliverable. Build it in five milestones, and keep a copy of the folder after each one.
- When it's finished, do **13 (peer review)** and **14 (wrap-up reflection)**. Those two complete the class.
- Do **12 (debug: a broken portfolio)** partway through — the middle of Milestone 4 is ideal. Every bug in it is one that people really make on this page.
- The **variants (02–06)** are other kinds of site built from the same skills. They're extra practice, not required: pick one if you want another rep after the portfolio.
- The **stretch goals (07–11)** come *after* the core brief is done. Some of them reach past what the course taught, and they say so.
- Put your code in `work/<assignment-slug>/`. See [work/README.md](work/README.md) for the folder layout.
- **Type everything by hand.** Save all three files. After every change, check the page **and** the Console.

## Scope — only what's been taught

Use only Class 1–8 material.

**In scope this class:**
- In-page links: `<a href="#contact">` jumps to the element with `id="contact"`
- Everything from Classes 1–7, combined on one page: semantic HTML and forms, CSS and the box model, Flexbox, Grid and media queries, JavaScript, the DOM and events

**Never taught in this course — use only where a brief says *(stretch)*:**
- CSS `position` (so: no sticky headers, no pop-ups that cover the page), transitions and animations, `:hover`, CSS variables
- `localStorage` (so: nothing is remembered after a reload), timers, scroll events, the clipboard, `fetch`
- DOM traversal (`parentElement`, `closest`), `dataset`, and array methods such as `.map`, `.filter`, `.sort`
- Inline handlers (`onclick="…"`) and inline styles (`style="…"`)
- Any library, framework, template, or website builder — the whole point is that you built it

## Definition of done for Class 8

- [ ] **01** is finished: your own portfolio, hitting every checklist item
- [ ] It opens with Live Server with **no red in the Console**
- [ ] Every nav link jumps to the right section
- [ ] It works from 320px to 1440px, in both themes, with no horizontal scrollbar
- [ ] The theme toggle, the thank-you form, and your third interaction all work
- [ ] Every word, colour, and project on the page is yours — nothing is left over from the lesson's example
- [ ] Debug 12 complete, with the cause of each bug written in your own words
- [ ] Peer review 13 done: you've scored your own page, and it scores **10 or more out of 14**
- [ ] Reflection 14 written
- [ ] You can open any of your three files, point at any line, and explain it
